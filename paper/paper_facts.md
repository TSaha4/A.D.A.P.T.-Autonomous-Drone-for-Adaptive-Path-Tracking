## 1. Problem and scope
- Converts a single annotated flood-map raster (flood pixels drawn in red) into a QGroundControl
  `QGC WPL 110` mission for a multirotor that visits one boundary drop point per flood region,
  releases a payload via a servo command, and returns home. [code: main.py]
- Offline, single-UAV, single-image, operator-in-the-loop for colour sampling. No onboard perception,
  no live replanning during flight, no real-time claims.

## 2. Inputs [code]
- Raster image (PNG). CLI positional `image_path` (default `data/input/varanasi.png`).
- `--display-width` (default 750 px), `--min-area` (default 200 px^2), `--lat`/`--lon` (default
  25.3176, 82.9739 = Varanasi city; used for weather query AND as ground position of the image centre),
  `--horizon` (default 2.0 h), `--dummy-weather` flag.
- Config (`config/settings.py`, env/.env): WEATHER_API_BASE_URL (Open-Meteo forecast endpoint),
  MAX_SAFE_WIND_SPEED 40.0, MAX_SAFE_PRECIPITATION 15.0 (warnings only), METERS_PER_PIXEL 2.0
  (no `.env` exists in the repo, so 2.0 is always used).
- Weather: Open-Meteo `current=precipitation,wind_speed_10m,wind_direction_10m,visibility`,
  `timezone=auto`, 10 s timeout, lru_cache(32); on failure returns calm fallback
  {0 mm, 0 km/h, 0 deg, 10000 m, status=fallback}. Visibility fetched but unused.
- Dummy weather `data/input/dummy_weather.json`: precipitation 10.0, wind 30.0, direction 270.0.

## 3. Pipeline (exact order in main.main) [code]
1. Arg validation: display width > 0 (argparse error, exit 2); preflight `pixel_to_latlon` on
   reference + METERS_PER_PIXEL (exit 2 if invalid) — before any work.
2. Weather: dummy file or API (+warning if fallback). Safety threshold warnings only (no abort).
3. `cv2.imread`; exit 1 if unreadable. Remove previous mission file only now (exit 1 if not removable).
4. Resize if W > display width: s = D/W, H' = round(H*s), INTER_AREA. Otherwise s = 1.
5. Interactive colour sampling: operator clicks flood pixels, presses 'c'. (Evaluation replaces
   the clicks with a deterministic simulated operator — see section 8.)
6. HSV thresholds: 11x11 patch (radius 5) around each click; lower = (min - margin), upper = (max +
   margin), hue margin 20, S/V margin 30, clipped to [0,179]/[0,255]. Red-wrap mode if lower_h <= 10
   or upper_h >= 170: hue bands [0,10] U [170,179] replace the computed hue range (S/V range kept).
7. Mask: cv2.inRange, then MORPH_CLOSE then MORPH_OPEN with 5x5 ones kernel.
8. Flood-spread prediction (rule-based "cellular automaton", morphological):
   b = max(0, floor(P/5)) px (P precipitation mm), w = max(0, floor(V/10)) px (V wind km/h),
   direction toward = wind_from + 180 deg; dx = round(sin(theta)*w), dy = round(-cos(theta)*w);
   iterations N = max(1, floor(horizon_h)); each iteration: dilate with ellipse (2b+1)^2 if b>0, then
   OR with copy shifted by (dx,dy) via warpAffine if w>0. Units are display pixels.
9. Obstacle mask O = M OR M_pred (bitwise_or).
10. Contours: findContours(RETR_EXTERNAL, CHAIN_APPROX_SIMPLE) on the CURRENT mask only; keep area
    >= min_area (200 px^2 default).
11. Per region: convex hull (edges) and image-moment centroid (int truncation); fallback first hull vertex.
12. Safe drop point per region: hull vertex minimising point-to-segment distance to the polyline that
    joins the region centroids in DISCOVERY order (not the final route). Single region => no segments
    => first hull vertex.
13. HOME = safe point nearest to integer pixel (W'//2, H'//2).
14. Route order: greedy nearest-neighbour from HOME over all safe points (HOME itself included, so it
    is visited first at distance 0); ordered list = [HOME, p_1..p_n, HOME].
15. Path planning per consecutive pair: obstacle mask downsampled by factor 5 with INTER_NEAREST
    (grid cell = 5 display px, only 1 of 25 pixels sampled); endpoints mapped by floor division;
    endpoints inside obstacles snapped by 8-connected BFS to nearest free cell (radius 10 cells; if none,
    warning and stays in obstacle); a NEW DStarLite instance is created per leg (no incremental reuse
    across legs); all obstacle cells are inserted before compute_shortest_path; 8-connected grid,
    edge cost Euclidean (1 or sqrt 2), heuristic Chebyshev (admissible), path extracted greedily from g.
    If no path: ERROR log and NO intermediate points are added, i.e. the mission flies a straight leg
    (may cross flood). Intermediate grid points are up-scaled as (5*gx, 5*gy) (cell corner).
16. Geographic conversion (G2, D1, D2 fixes applied): reference pixel c = ((W'-1)/2, (H'-1)/2);
    k = METERS_PER_PIXEL / s; E = (x - cx) k, N = (cy - y) k;
    lat = lat0 + N/111320; lon = lon0 + E/(111320 cos lat0); rejects non-finite inputs, k <= 0,
    |lat0| >= 90, |lon0| > 180, pole crossing, |dlon| >= 180; wraps lon only when outside [-180,180].
    All points converted before the file is opened (no partial file).
17. Mission (QGC WPL 110, tab separated, frame 3 = GLOBAL_RELATIVE_ALT):
    seq0 HOME (cmd 16, current=1, alt 0); seq1 NAV_TAKEOFF (22) alt 100 at HOME;
    for each path point (skip first if it is HOME): NAV_WAYPOINT (16) alt 100; if drop index and not
    first/last: NAV_LOITER_TIME (19) p1=5 s alt 100, NAV_WAYPOINT alt 10, DO_SET_SERVO (183)
    p1=servo channel 9, p2=PWM 2000, NAV_WAYPOINT alt 100; then NAV_RETURN_TO_LAUNCH (20) alt 100,
    NAV_LAND (21) alt 0 at HOME. Defaults: base_altitude 100 m, drop_altitude 10 m.
18. Visualisation (matplotlib/OpenCV). Output path `data/output/enriched_drone_mission.waypoints`.

## 7. What is NOT established (must never be claimed)
- Real-world georeferencing of the supplied maps; defensible METERS_PER_PIXEL for them.
- Mission Planner / QGroundControl load test; ArduPilot or PX4 SITL; HITL; physical flight.
- Segmentation accuracy (no ground truth masks): no IoU/precision/recall.
- Flood-spread prediction accuracy (heuristic, uncalibrated, never compared with observations or
  hydrodynamic models).
- Drop-point safety (no terrain/population/obstacle data; "safe" = boundary vertex of flood hull).
- Real-time performance; scalability claims beyond the measured inputs.

## 8. Evaluation protocol decisions
- Simulated operator: clicks = centroids of the 8 largest connected components of pixels with
  (H <= 5 or H >= 175) and S > 180 and V > 180 in the display image. Deterministic.
- Dummy weather used for reproducibility (live API values change); live API smoke-tested only.
- All experiment code lives in paper/experiments and calls the unmodified pipeline (main.main or src/*).

## 10. MAVLink / autopilot semantics (documentation review only, not SITL)
- Param slots match MAVLink common.xml for 16/19/20/21/22/183.
- ArduCopter: DO commands run when the preceding NAV command completes (servo fires on reaching 10 m);
  WAYPOINT yaw (param4) unsupported on Copter; RTL "generally should be the last command" (LAND after
  RTL never runs); TAKEOFF climbs from current location (lat/lon ignored); seq 0 holds vehicle home.
- PX4: param4 yaw = 0 => face north at each waypoint (NaN would mean default heading).
