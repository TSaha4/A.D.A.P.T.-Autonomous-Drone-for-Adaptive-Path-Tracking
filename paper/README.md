## Reproducing the results

From the repository root, with the venv activated
(`pip install -r paper/experiments/requirements-paper.txt`):

```
python paper/experiments/e2e_maps.py                  # E1  (~50 s)
python paper/experiments/ablation_and_sensitivity.py  # E2, E3 (~20 min)
python paper/experiments/tsp_optimality.py            # E4
python paper/experiments/planner_baseline.py          # E5 (run alone: timings)
python paper/experiments/geodesy_eval.py              # E7
python paper/experiments/mutation_eval.py             # E8 (~30 min; uses a temporary copy)
python paper/experiments/map_scale_estimate.py        # E9
python paper/experiments/env_and_tests.py             # E10
python paper/experiments/multi_uav_comparison.py      # E11 single vs. multi-UAV (~5 min, parallel) -> Table IX
python paper/experiments/multi_uav_comparison.py --scale-check   # E11b at landmark-estimated scales
python paper/experiments/multi_uav_equivalence.py REFERENCE_DIR  # E12 vs. the reference implementation
python paper/experiments/multi_uav_clusters.py       # E13 how the fleet divides flood regions among drones
python paper/experiments/make_figures.py              # figures
python paper/experiments/audit_manuscript.py          # manuscript consistency checks
```

All experiments run the unmodified pipeline. The deterministic "simulated operator" replaces the
interactive click step; see `experiments/common.py`.

## Replacing figures

- **Data figures** are regenerated from results; change `experiments/make_figures.py`, not the PDFs.
- **Input-map panels:** Figs. 2–3 reproduce third-party map images. Replace them, or obtain
  permission (see TODO).
- **To add a figure** (e.g. a Mission Planner screenshot after a ground-station test), put the file
  in `figures/` and add a `figure` environment with a caption, a label and an in-text `\ref`.
- **Simulation placeholders:** nine `\simplaceholder{...}` frames mark where your own simulation
  screenshots go (input map, region detection, drop points, single-UAV route, multi-UAV allocation,
  multi-UAV routes, UAV simulation, mission execution, single vs. multi). `TODO_for_authors.md`
  (section 1b) lists each one with the command that produces the image.
